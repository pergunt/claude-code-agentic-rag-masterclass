# 1.3 LangSmith Tracing

✅ **Simple**: a few lines in `services/llm.py` plus config. Depends on 1.2.

Parent: `1.module-1-overview.md`

## Tasks

1. Wrap the OpenAI client in `services/llm.py` with `langsmith.wrappers.wrap_openai(OpenAI())`. Decorate `stream_reply` with `@traceable(name="chat_turn", run_type="chain")` and pass `metadata={"thread_id", "user_id"}`. Log no message content beyond what the OpenAI wrapper already logs.
   - *Validate:* `python -c "import app.services.llm"` succeeds.
2. Config: `LANGSMITH_TRACING=true`, `LANGSMITH_API_KEY`, `LANGSMITH_PROJECT=agentic-rag-masterclass`. Tracing is a no-op when these are unset.
   - *Validate:* with `LANGSMITH_TRACING` unset, the app boots and `/health` responds.
3. If `wrap_openai` doesn't capture streamed Responses output in the installed version, fall back to logging the final text manually in the `traceable` outputs.
   - *Validate:* send a chat message. The LangSmith project shows a `chat_turn` run with the nested OpenAI call, the input, the streamed output and the thread/user metadata.
