# 2.2.1 Shared app header (Sign out on every page)

✅ **Simple**: frontend only, 2 new components, 4 edited files, no backend or API changes.

## Goal
Every signed-in page shows the same header at the top, rendered once by a layout route:
- left: app name "Agentic RAG" (link to `/`), then nav links **Chat** (`/`) and **Documents** (`/documents`)
- right: the user's email and a **Sign out** button

Sign out then exists everywhere (chat, any thread, documents, and any future page under the layout). The login page has no header.

Out of scope: PDF upload (deferred to Module 5 per the user), any backend change, mobile/responsive menus, theming.

## Tasks

### 1. `frontend/src/components/AppHeader.tsx` (new)
```tsx
export function AppHeader()
```
- Uses `useAuth()` for `session` and `signOut`, and `useLocation()` for the active link.
- Markup: `<header className="flex h-12 shrink-0 items-center gap-4 border-b px-4">`.
  - `<Link to="/" className="text-sm font-semibold">Agentic RAG</Link>`
  - `<nav className="flex items-center gap-1">` with two `Button size="sm" asChild` wrapping `Link`s:
    - Chat: `MessageSquare` icon + "Chat", to `/`
    - Documents: `FileText` icon + "Documents", to `/documents`
    - Active link uses `variant="secondary"`, inactive `variant="ghost"`. Documents is active when `pathname.startsWith('/documents')`; Chat is active otherwise. Set `aria-current="page"` on the active link.
  - Spacer `<div className="flex-1" />`
  - `<span className="truncate text-xs text-muted-foreground">{session?.user.email}</span>`
  - `<Button size="sm" variant="ghost" onClick={() => void signOut()}><LogOut /> Sign out</Button>` (visible text "Sign out", so its accessible name is "Sign out")
- Icons from `lucide-react`. Import style: copy `components/chat/ThreadSidebar.tsx` (`@/components/ui/button`, `react-router`).
- Sign-out redirect needs no code: `ProtectedRoute` already sends a signed-out session to `/login`.

### 2. `frontend/src/components/AppLayout.tsx` (new)

### 3. `frontend/src/App.tsx`: layout route
Replace the three separately wrapped protected routes with one pathless layout route:
```tsx
<Route
  element={
    <ProtectedRoute>
      <AppLayout />
    </ProtectedRoute>
  }
>
  <Route path="/" element={<ChatPage />} />
  <Route path="/t/:threadId" element={<ChatPage />} />
  <Route path="/documents" element={<DocumentsPage />} />
</Route>
```
Keep `/login` and the `*` → `/` redirect as they are.

- Stop passing `email` and `onSignOut` to `ThreadSidebar`. Drop `signOut` from the `useAuth()` destructure. If `session` is then unused, drop it too (check first: it may be used elsewhere in the file).

### 6. `frontend/src/pages/DocumentsPage.tsx`
